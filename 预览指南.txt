# 📱 移动端界面预览指南

## 🎯 快速开始

### 方式一：预览页面（推荐）⭐⭐⭐⭐⭐

**步骤：**
```
1. 双击打开 mobile-preview.html
2. 在浏览器中查看两个手机框架中的移动界面
3. 可以对比 iPhone 和 Android 两种视图效果
```

**优势：**
- ✅ 真实手机外框模拟
- ✅ 同时展示多个视角
- ✅ 包含功能介绍
- ✅ 支持全屏打开
- ✅ 支持生成二维码

---

### 方式二：直接访问移动版 ⭐⭐⭐⭐

**步骤：**
```
1. 双击 dashboard-mobile.html
2. 在浏览器中全屏查看移动界面
3. 按 F12 切换到移动设备模式
```

**浏览器开发者工具：**
- **Chrome**: F12 → Ctrl+Shift+M → 选择设备
- **Edge**: F12 → Ctrl+Shift+M → 选择设备
- **Firefox**: F12 → Ctrl+Shift+M → 选择设备

**推荐设备尺寸：**
- iPhone 12 Pro (390x844)
- iPhone 14 Pro Max (430x932)
- Samsung Galaxy S20 (360x800)

---

### 方式三：新窗口打开 ⭐⭐⭐⭐

**步骤：**
```
1. 在 mobile-preview.html 页面点击"在新窗口打开"按钮
2. 或在 dashboard-mobile.html 上右键 → 在新窗口打开
3. 调整浏览器窗口大小为手机比例
```

## 💡 使用技巧

### 1. 最佳观看体验
- 使用 **mobile-preview.html** 获得完整预览体验
- 浏览器缩放调整为 100%
- 屏幕分辨率建议 1920x1080 以上

### 2. 对比测试
- 同时打开 PC 版（index.html）和移动版
- 对比不同设备上的显示效果
- 检查响应式布局适配

### 3. 功能演示
- 点击底部 Tab 切换（虽然只是 UI 展示）
- 点击周期按钮切换图表维度
- 滚动查看完整页面内容

### 4. 开发调试
```javascript
// 在控制台可以测试功能
updateTime(); // 更新时间
// 模拟数据刷新
```

## 🔧 自定义修改

### 修改手机框架颜色
编辑 `mobile-preview.html`，找到：
```css
.phone-frame {
    background: #000;  /* 修改手机边框颜色 */
}
```

### 修改背景渐变
```css
body {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    /* 修改这里的颜色值 */
}
```

### 添加更多手机框架
复制 `.phone-frame` 结构，添加到 `.preview-grid` 中。

## 📱 实际手机测试

### 方式一：本地服务器
```bash
# 启动 HTTP 服务器
python -m http.server 8080

# 获取本机 IP
ipconfig  # Windows
ifconfig  # Mac/Linux

# 手机访问
http://你的IP地址:8080/dashboard-mobile.html
```

### 方式二：二维码扫描
1. 在 preview 页面点击"扫码访问"
2. 使用微信或浏览器扫描二维码
3. 手机自动打开移动界面

### 方式三：局域网共享
将文件放到局域网服务器，手机直接访问 URL。

## 📞 常见问题

**Q: 为什么手机框架显示不正常？**
A: 确保浏览器缩放为 100%，或尝试刷新页面。

**Q: 如何在手机上查看？**
A: 使用局域网服务器或直接发送文件到手机。

**Q: 能否自定义手机外框颜色？**
A: 可以，修改 CSS 中的 `.phone-frame` 样式。
